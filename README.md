# Marilyn Nguyen Portfolio

A responsive, one-page CV and portfolio site built with HTML5, Bootstrap 5, custom CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a modern browser. No build step or server is required.

## Included content

- Contact email, education, projects, and work experience reflect the supplied resume.
- Profile photo and a downloadable copy of the supplied resume are in `assets/`.
- The WhatsApp link intentionally uses `[AddWhatsAppNumber]` because no WhatsApp number was provided. Replace it in `index.html` with an international number containing digits only, such as `14165551234`.

## Structure

```
index.html          Main semantic page and SEO structured data
css/style.css       Visual design and responsive styles
js/script.js        Scroll/reveal and navigation interactions
assets/             Photo, CV PDF, and favicon
```

## Notes

Bootstrap and Google Fonts load from their CDNs. The site includes semantic landmarks, descriptive image text, keyboard skip navigation, responsive navigation, and schema.org person data for search and answer engines.
